# AWS EC2 Express Server Sample

AWS EC2(Ubuntu) 환경에서 Node.js와 Express, 그리고 PM2 프로세스 매니저를 활용하여 백엔드 서버를 구축하고 배포하는 실습 프로젝트입니다.

---

## 🛠️ Tech Stack

- **OS:** Ubuntu 24.04.5 LTS (AWS EC2)
- **Runtime:** Node.js (v22.x)
- **Framework:** Express.js
- **Process Manager:** PM2

---
